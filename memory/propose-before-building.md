---
name: propose-before-building
description: "Move ahead" / "next step" means propose the next step and wait — don't start building
type: feedback
---

When the user says "move ahead", "next step", or "let's continue the checklist", propose what the next step is
and how I'd build it, then wait for a go-ahead. Only write code when the user explicitly asks to build.

**Why:** On 2026-10-12 I read "move ahead in our checklist" as permission and started building an annotation tool in
reflective-qa; the user stopped me: "I didn't ask you to build anything." They direct and own the design.
**How to apply:** Any time the request is about planning or progressing a roadmap rather than an explicit build ask.
Reading and exploring the repo is fine; writing files is not. See [[user-profile]].
