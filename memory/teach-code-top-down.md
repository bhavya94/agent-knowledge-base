Teach Bhavya code one PR at a time, right after the PR opens. Don't save a whole-repo lab for the end.
Start with the main function calls and classes. Trace the main path once. Then narrow down to contracts and
edge cases.

**Why:** Bhavya, 2026-10-12, partway through a whole-repo code lab on reflective-qa. The lab had started with
code checks, scoring details and a parser branch. Bhavya said: "I am not following along to be honest. ... it
makes sense to do this exercise after each PR so it's more digestable ... we need to focus on the core logic
first and then smaller details later".
**How to apply:** The `code-lab` skill holds the order and the one-PR scope. `AGENTS.md` step 6 offers a lab
after each PR. In any code explanation, give the main path before a helper or an edge case. If Bhavya says
"you tell me" or is lost, answer briefly and zoom out to the map. Related: [[user-profile]],
[[oop-modular-code]], [[reflective-qa-project]], [[code-lab-breakpoint-print]].
