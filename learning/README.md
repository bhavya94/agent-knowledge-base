## Every note answers four questions
1. **What problem?** What fails or is hard without this?
2. **What idea?** The core mechanism, in a few sentences. A diagram if it helps.
3. **Why it matters:** when it beats the alternatives, what it costs, where it breaks.
4. **How I'd use it:** a concrete application, ideally in [`roadmap.md`](roadmap.md).

Distill, don't transcribe: no copied slides, transcripts, or code from paid courses.
Create a module's file only after finishing that module.
